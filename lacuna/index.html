What Remains and What Is Missing? Learning Point Cloud Semantic Representations for Partial Observations

Chun-Peng Chang1, Shaoxiang Wang2, Alain Pagani3, Dariu Gavrila1, Holger Caesar1
1TU Delft, Cognitive Robotics 2RPTU 3DFKI, Augmented Vision
Paper Code (coming soon)

Abstract

Self-supervised learning (SSL) yields strong 3D point cloud representations, yet models are primarily evaluated on complete scenes. Robotic agents, by contrast, observe partial scenes due to limited viewpoints and occlusions, raising two questions: can these models (1) understand visible regions in partial inputs, and (2) infer what lies where points are missing without costly 3D completion? Because state-of-the-art 3D SSL methods rely on masked pretraining, one might expect them to handle incomplete point clouds naturally. Surprisingly, performance degrades sharply once points are absent. We show this stems from pretraining design rather than model or data scale: mask tokens reveal the geometry they should hide, compounded by suboptimal backbones and learning frameworks. We propose Lacuna, an SSL point cloud pretraining framework that addresses these issues by removing masked points and predicting their latent features directly from visible context. Using up to 4.8× fewer parameters and less pretraining data, Lacuna remains far more robust under missing points and predicts dense semantic features in unobserved regions without explicit completion. Code and weights will be released.
